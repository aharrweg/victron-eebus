Dienst auf dem Cerbo einrichten (Shell)

Melden Sie sich per SSH auf dem Cerbo an und richten Sie den Autostart über den Venus-OS-Supervisor ein:

# 1. Verzeichnisse anlegen
mkdir -p /data/apps/eebus/service/log
mkdir -p /data/apps/eebus/cert
mkdir -p /data/apps/eebus/log

# 2. Rechte setzen
chmod +x /data/apps/eebus/eebus-cerbo

# 3. Run-Skript erstellen
cat << 'EOF' > /data/apps/eebus/service/run
#!/bin/sh
exec 2>&1
exec /data/apps/eebus/eebus-cerbo
EOF
chmod +x /data/apps/eebus/service/run

# 4. Logger-Skript erstellen
cat << 'EOF' > /data/apps/eebus/service/log/run
#!/bin/sh
exec multilog t s25000 n4 /data/apps/eebus/log
EOF
chmod +x /data/apps/eebus/service/log/run

# 5. Dienst aktivieren
ln -s /data/apps/eebus/service /service/eebus

# 6. Update-Schutz in rc.local hinterlegen
grep -q "/service/eebus" /data/rc.local 2>/dev/null || cat << 'EOF' >> /data/rc.local
if [ ! -L /service/eebus ]; then
    ln -s /data/apps/eebus/service /service/eebus
fi
EOF
chmod +x /data/rc.local

Prüfen Sie den Status mit:
svstat /service/eebus


3. Pairing: Eigener SKI und Steuerbox koppeln

EEBUS nutzt gegenseitige Authentifizierung über sogenannte SKI (Subject Key Identifier). Der Cerbo und die Steuerbox des Messstellenbetreibers/Netzbetreibers müssen sich gegenseitig kennen.

Eigenen Cerbo-SKI ermitteln: 
cat /data/apps/eebus/log/current | tai64nlocal | grep "SKI"

Diesen SKI tragen Sie in der Konfiguration/Weboberfläche der Steuerbox bzw. des SMGW als Gegenstelle ein. 
(Hinweis: Die Anmeldung neuer Steuerboxen am Cerbo erfolgt automatisch, sobald diese im selben Netzwerk gefunden werden. Alternativ kann ein SKI manuell über Node-RED registriert werden, siehe Beispiel-Flow).

Der komplette, aktuelle Node-RED Flow für § 14a (Verbrauch) und EEG (PV-Limit) befindet sich nun in der separaten Datei `nodered_example.json` im Hauptverzeichnis des Repositories.

Test-Payload direkt per MQTT (für manuelle Tests über die SSH-Konsole)

# Test: § 14a Dimmung auf 4.200 W aktivieren
mosquitto_pub -h 127.0.0.1 -t "eebus/grid/limit" -m '{"active":true,"power_limit_w":4200}'

# Test: § 14a Dimmung aufheben (Normalbetrieb)
mosquitto_pub -h 127.0.0.1 -t "eebus/grid/limit" -m '{"active":false,"power_limit_w":0}'

# Test: EEG PV-Einspeisung auf 6.000 W drosseln
mosquitto_pub -h 127.0.0.1 -t "eebus/pv/limit" -m '{"active":true,"power_limit_w":6000}'

# Test: EEG PV-Einspeisung aufheben (100%)
mosquitto_pub -h 127.0.0.1 -t "eebus/pv/limit" -m '{"active":false,"power_limit_w":0}'
